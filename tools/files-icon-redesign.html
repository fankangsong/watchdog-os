Files · 图标重设计

32×32 · string-array pixel art · Mac OS 9 / Platinum · 生成自 tools/pixel-icon.py

改动理由

  1. 按参考图换造型（本轮）：不再用蓝梯形透视，改成小圆角橙黄 tab 在后（x2..16 / y3..13，下部被盖住只露 y3..7）+ 大圆角浅黄面板在前（x1..30 / y8..29，占约 80% 面积）。tab 宽约为面板一半、露出高度约 18%，比例对齐参考图。
  2. 柔和渐变代替深色描边：新增 J（#ffc233 橙黄）/ V（#ffeaa8 浅黄）两色；前片顶部一条 W 亮高光 = 敞口线，中部 V 浅黄，底部 y → Y 逐行收窄压深；外框改用暖色 o 而非 K / N 硬黑边。
  3. 配色随参考图改为暖黄：桌面语义由「蓝 = Files」变为「暖黄 = Files」。与 Editor 的琥珀笔记本靠形状区分 —— 本版是纯色块 + 圆角，没有书脊 / 绑带 / 书签带。
  4. 保留独立主体，无窗口外框：仍不画条纹标题栏与 1px 黑边，文件夹占满画布、四周留 1~3px 透明边，与 watchdog / converter / editor 一致；16px 缩略下「小 tab + 大面板」依旧清楚。
规范约束（docs/design-spec.md §7.4）：viewBox 0 0 32 32、仅 <path> 无 <text>/<font>、 shape-rendering="crispEdges"、体积 < 4 KB、光源左上（高光 + 暗边，不加投影）、 import 必须带 ?no-inline。本版按参考图改为暖黄渐变 + 圆角，独立主体无外框。
本页零外部依赖：像素数据内联为 ART（name / width / height / palette / pixels），CSS Grid 逐格渲染。换图标后老用户需清 localStorage.classicyDesktopState 才能看到新图标。
