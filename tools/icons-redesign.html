统一规范

WatchDog OS（齿轮）、Converter（交换箭头）、Editor（笔记本封面）与 Files（文件夹）用独立主体直接落在透明底上，其余共用同构 Mac OS 9 窗口外框（条纹标题栏 + 1px 黑边 + 右下暗边）， 光源统一左上。关键元素按 2px 栅格对齐偶数坐标，保证 2×2 多数票降采样到 16px 后不糊。 Converter 的双箭头由同一轮廓镜像叠压，前层整圈描边做前后分层。 viewBox 0 0 32 32、仅 <path>、 shape-rendering="crispEdges"、< 4 KB、import 带 ?no-inline（docs/design-spec.md §7.4）。

本页零外部依赖：像素数据内联为 ART（name / width / height / palette / pixels），CSS Grid 逐格渲染。 换图标后老用户需清 localStorage.classicyDesktopState 才能看到新图标。
