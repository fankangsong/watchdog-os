32×32 · string-array pixel art · Mac OS 9 / Platinum · 生成自 tools/pixel-icon.py --ledger

设计约束与取舍

  1. 避开瞳孔：32px 上的同心圆极易读成眼睛（Disks 的盘面就是这么被否决的）。三案分别用 ¥ 横杠 / 横向层叠 / 中央方孔破掉「深色盘面 + 中心圆点」。
  2. 配色不跳：复用 Blog 铅笔、Converter 箭头那支琥珀 y / Y / o，只新增 Q #8a6520（深铜侧边 / 齿纹 / 压印）与 j #fff2c0（左上高光）两档。与 Files 的暖黄文件夹靠形状（圆 / 层叠 / 方孔）而非色相区分。
  3. 2px 栅格：关键元素 ≥2px、起点对齐偶数坐标；¥ 从 (12,10) 起、方孔从 (12,12) 起，2×2 多数票降采样到 16px 后仍是清晰色块。齿纹、压印线是 32px 专属，缩略后并回币面。
  4. 光源左上：高光在顶/左、暗边在底/右，不加投影；外框 1px K 同时把币面与厚度层「切」开，和 Chat 前气泡压后气泡同一手法。
规范（docs/design-spec.md §7.4）：viewBox 0 0 32 32、仅 <path> 无 <text>/<font>、shape-rendering="crispEdges"、体积 < 4 KB；import 必须带 ?no-inline。
换图标后老用户需清 localStorage.classicyDesktopState 才能看到新图标。备选方案 SVG 见 tools/preview/ledger-stack.svg 与 ledger-cash.svg。
